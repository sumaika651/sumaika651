## 🔭 What I'm Working On
- ### Invoice Crosschecker
An automation tool that verifies invoice data before it goes out, cutting manual checking time.
- Reads invoice spreadsheets and compares them against a reference database
- Automates a web portal to fetch order receipts (PDFs) for verification
- Runs blend/composition and TDS lookups as part of the check
- Writes a dated, checked Excel report highlighting discrepancies
- Includes a user manual and setup guide for non-technical users

**Tech:** Python, Excel automation (openpyxl/pandas), browser automation
- ### Textile Importer Research Tool
Turns raw monthly export reports into a researched list of potential importers.
- Filters textile-related importers from large Excel export datasets
- Uses the Serper (Google Search) API to find company websites and contact details
- Caches results in JSON to avoid repeat API calls and reduce cost
- Watchdog script restarts the run if it stalls, so long jobs finish
- Produces clean Excel output and includes a user manual

**Tech:** Python, Serper API, pandas, Excel
